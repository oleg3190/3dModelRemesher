## Проверенные архитектурные инварианты (не нарушать)


1. **Порядок stage4:** партиция → пересчёт `is_cut_edge`/стоп-узлов → трассировка путей → сборка петель. Никогда не менять `face_patch` после трассировки: это рождает Т-узлы на уже построенных путях → `users=3–4`, `fwd|fwd` → швы рвутся (S15, S17, S18, S19).
2. **Один путь = ровно одна пара патчей.** Стоп-узел: ≥3 различных `patch_id` в веере граней, либо открытый край с ветвлением графа разрезов.
3. **Запись петли = сегмент пути, а не исходное ребро.** Иначе семплы пути добавляются K раз → взрыв полигонов (388k, S08).
4. **N ≥ #путей — полигонный взрыв.** Пути короче половины ячейки получают `divisions = 0` (оба соседа видят одинаковый ноль → шов идентичен); на контур гарантируется ≥4 семплов boost'ом по ДЛИННЕЙШИМ путям; чётность — GF(2) с fallback на дубликацию семпла.
5. **Оба соседа обязаны использовать один id пути и один набор семплов**; правки плотности — только глобально согласованные (никаких локальных bump'ов).
6. **Параметризация требует диска** (χ=1, одна простая граница). Склейка компонент «шипом» запрещена. K>1 → сплит (2 разреза + flood); отказ → поглощение в соседа с ОБЯЗАТЕЛЬНОЙ переобработкой соседа.
7. **untangle/релакс живут в диапазоне площади + с якорным капом** — иначе морщины (+19% площади, S03).
8. **Заплатки** ставить после санитайзера, лимит 20–30 вершин + `is_open_border`. Заплатка на 40–208 вершин = симптом дыры в сборке, а не лечение (S14).
9. **Сначала диагностика, потом правка:** `[stage4/border]` (истинная граница vs покрытие), `[stage5/seam]` (два соседа + направление), `[stage6/area]` (таймлайн площади), свой двухсторонний chamfer/Hausdorff.
10. **Оценщик должен моделировать реальный распределитель** делений (округление → boost → чётность), иначе калибровка врёт на малых бюджетах (S12, S19, S20).
11. Каждый архитектурный шаг — замер «было → стал» по: boundary, non-manifold, компоненты, полигонов/цель, median SJ, aspect p95, Hausdorff, время, детерминизм.
12. **Полное покрытие контуров (`missed_edges = 0`) не гарантирует клейки швов.** После КАЖДОЙ волны слияния/абсорба/сплита нужно смотреть `[stage5/seam]`: открытые рёбра при users=2/противоположных направлениях и вырожденные слоты — это уже дефекты ПАРАМЕТРИЗАЦИИ (дубли индексов в контуре), а не потери путей. Пример: S20 — missed 0, но boundary 15.3% из-за 488 вырожденных слотов и 198 рёбер «users=1» (ring-пути).
13. **`missed_edges` — НЕ целевая метрика.** Целевые: boundary%, non-manifold, компоненты, SJ, aspect. Reorder партиции ради missed=0 (S19–S23) достиг покрытия ценой рваных швов и деградировал boundary 1.63%→12.5%, SJ 0.568→0.435, компоненты 1→92. Покрытие лечить только правкой, НЕ меняющей порядок «партиция→пути→петли» (S16/S18 это же и сломали).
14. **Потолок Scaled Jacobian задаёт РАЗРЕШЕНИЕ сетки патча, а не interior-солвер.** На coarse-бюджетах avg_nu≈2 (сетки 2×2) — форму квадов запирают 8 фиксированных Dirichlet-углов границы, interior-узлу негде ортогонализироваться. Медиана монотонна по бюджету (0.48@1000→0.775@20000). Значит «поднять SJ» решателем (Laplacian/Coons/untangle) вышеPlateau нельзя — нужен либо min interior-разрешение (nu,nv≥3), либо ортогональная пере-расстановка border-узлов (двигать парно на общих путях). Итерационный солвер (Jacobi→GS, equal→uniformizing, guarded-snap) замерен и нейтрален.
